# Additions-to-my-defense

Interactive educational micro-site titled: **Additions to My Defense: The Legalistic Mind of Dr. José Rizal** (*Adiciones a Mi Defensa*, December 26, 1896).

Includes a dedicated section on Rizal's earlier memorandum to his counsel, **Data for My Defense** (December 12, 1896), with the full text, editor's footnotes, and analysis.
